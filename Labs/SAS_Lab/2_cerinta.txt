Exerciţiul 15: Un comerciant dorește să prognozeze vânzările de băuturi răcoritoare în unul din punctele sale de vânzare. Pentru aceasta a notat vânzările din primele douăzeci și cinci de zile ale lunii iunie, precum și temperaturile înregistrate în aceste zile. Se cere să se determine dacă există corelație semnificativă între vânzările de răcoritoare și temperatură și să se estimeze vâzările din ziua de 26 iunie, dacă temparatura prognozată este de 32 grade. Datele să găsesc în fișierul “racoritoate.txt”.
*Analiza de regresie;
DATA racoritoare;
	INFILE "/home/nume.prenume/racoritoare.txt";
	INPUT Data: MMDDYY. Vanzari Temperatura;
RUN;
PROC PRINT data=racoritoare;
	FORMAT data DDMMYY.;
RUN; 
PROC CORR  data=racoritoare;
	VAR Temperatura;
	WITH Vanzari;
	TITLE "Corelatia intre vanzarile de racoritoare";
RUN;
PROC REG data=racoritoare;
	MODEL Vanzari=Temperatura;
	PLOT Vanzari*Temperatura;
	TITLE "Rezultatele analizei de regresie";
RUN;

----------------------------

1. Importul date

DATA racoritoare;
	INFILE "/home/nume.prenume/racoritoare.txt";
	INPUT Data: MMDDYY. Vanzari Temperatura;
RUN;

	•	Creează setul de date racoritoare.
	•	Citește fișierul racoritoare.txt cu trei coloane: Data, Vanzari, Temperatura.
	•	Data este interpretată în format MM/DD/YYYY.

2. Afișarea datelor formatate 

PROC PRINT data=racoritoare;
	FORMAT data DDMMYY.;
RUN;

	•	Afișează conținutul tabelului.
	•	Formatează data în stil european (DD/MM/YYYY).

3. Analiza corelației:

PROC CORR data=racoritoare;
	VAR Temperatura;
	WITH Vanzari;
	TITLE "Corelatia intre vanzarile de racoritoare";
RUN;

	•	Analizează corelația dintre Vanzari și Temperatura.
	•	Corelația este o măsură statistică care arată cât de mult variază două variabile împreună.
	•	Verifică dacă există o relație lineară între ele.

4.	Analiza de regresie:

PROC REG data=racoritoare;
	MODEL Vanzari=Temperatura;
	PLOT Vanzari*Temperatura;
	TITLE "Rezultatele analizei de regresie";
RUN;

	•	Construiește un model de regresie liniară: Vanzari în funcție de Temperatura.
	•	Generează un grafic al relației dintre cele două variabile.
	•	Furnizează coeficienți, eroare standard, R² etc.
